# 🛒 ShopEase — eCommerce Homepage UI  
A clean, responsive, Amazon-inspired eCommerce homepage built using **HTML, CSS, and JavaScript**.  
This project showcases a modern UI layout with a hero slider, navigation bar, category cards, and footer — suitable for portfolios, internships, and frontend development practice.

🌐 **Live Demo:**  
🔗 https://udayraika18.github.io/Shop-Ease-eCommerce/

---

## 🚀 Features

- ✔️ Fully responsive layout  
- ✔️ Amazon-style navbar with search bar and menu  
- ✔️ Auto-sliding hero banner  
- ✔️ Evenly spaced category cards  
- ✔️ Modern footer section  
- ✔️ Clean and well-commented code  
- ✔️ 100% safe, no trademarked assets  
- ✔️ Hosted using GitHub Pages

## 🧩 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Udayraika18/Shop-Ease-eCommerce.git
   ```
2. Navigate to the folder:
   ```bash
   cd Shop-Ease-eCommerce
   ```
3. Open the project:
   Simply open `index.html` in your browser.
